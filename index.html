Cloud Misconfiguration Detector

A Cloud Security Posture Management tool for AWS. I'm using Terraform to deploy a small set of cloud resources — a storage bucket, an IAM role, and a VM — deliberately configured with common real-world misconfigurations: a public bucket, an over-permissive IAM policy, unencrypted storage, and an open security group.

I'm scanning the Terraform configuration with Checkov to catch and document each issue, and writing my own Python script to parse the configs and flag the same misconfigurations independently — applying the same algorithmic, data-driven approach from my MedMonitor risk-prediction work to cloud risk detection.

about me

I'm a Mathematics and Computer Science graduate with a strong focus on secure software engineering and applied machine learning. My dissertation, MedMonitor Intelligence, centered on building an iOS app for cardiovascular risk prediction, where security and privacy were foundational. I implemented encrypted local storage, biometric authentication, and privacy-by-design strategies to protect sensitive health data and ensure full compliance with UK GDPR.

My interest in cybersecurity was sparked while developing MedMonitor Intelligence. Working with realistic healthcare data made me realise what’s truly at stake: as medical records move online, the risk to patient privacy grows, and those most affected are the people whose data we protect. This shifted my mindset—security measures like encryption, credential hashing, and biometric access weren't afterthoughts, but core design decisions from the very beginning.

I'm now committed to advancing a career in cybersecurity, with a particular passion for secure application development, cloud security, and leveraging data science to strengthen threat detection. Above all, I want to help defend the critical systems people rely on—especially in healthcare, where the consequences of a breach are measured not just in downtime, but in patient trust and safety. This portfolio brings together the projects I've built so far and those I continue to develop as I grow in this field.

I'm currently looking for opportunities in cyber security where I can apply what I've learned to real-world problems — whether that's red teaming, security engineering, or secure application development.

projects

Selected work from my degree and personal projects that demonstrate my skills in cyber security and software development.

MedMonitor Intelligence

MedMonitor Intelligence, an iOS app for advanced cardiovascular risk assessment, leveraging on-device machine learning (LightGBM via Core ML) and SHAP-driven explainability. Security and privacy were integral from inception: health data is encrypted at rest using Core Data encryption, credentials are hashed with CryptoKit, access is protected by biometric authentication, and strict session timeouts are enforced. Every safeguard aligns with UK GDPR standards for handling sensitive health data, setting a benchmark for privacy-by-design in mobile health technology.
